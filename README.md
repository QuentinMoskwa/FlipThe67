Jeu de carte en multijoueur en ligne, développé en JS avec NodeJS, Socket.IO, React, Express et Vite dans le cadre du séminaire de développement appliqué aux jeux vidéo de EFFICOM.

# Instructions pour lancer le projet
## Côté serveur
1. cd server
2. npm install
3. npm run dev

## Côté client
4. cd client
5. npm install
6. npm run dev


Attention il faut avoir node en 24.14.0 minimum pour que le projet fonctionne correctement.
Pour cela utilisez juste nvm use dans le terminal, le fichier .nvmrc contient la version de node à utiliser. Si vous n'avez pas nvm, vous pouvez l'installer en suivant les instructions sur le site officiel : https://github.com/nvm-sh/nvm
